### 2️⃣ Scalar Vortex Coronagraph: Charge and Aberration Analysis with HCIPy

🔗 **[View Simulation Code and Results](https://github.com/ForouzanHabibi/HCIPy_Vortex_Coronagraph_GitHub_Ready)**

- Developed a **Python/HCIPy simulation workflow** for scalar vortex coronagraphs with topological charges **2, 4, and 6**.
- Investigated sensitivity to **Zernike wavefront aberrations**, including defocus, astigmatism, and coma.
- Evaluated **stellar leakage, point-spread functions (PSFs), and off-axis point-source throughput**.
- Compared the trade-off between **stellar suppression and off-axis throughput** for different topological charges.
- Performed **numerical resolution and convergence checks** to assess the stability of the simulated results.
- Analyzed the influence of low-order aberrations on high-contrast optical imaging performance.

**Tools:** Python, HCIPy, NumPy, Matplotlib.

**Scope:** Numerical analysis using an idealized scalar vortex coronagraph model.
